method · how the AI is run
Gates
Hooks stop the AI before it acts: a commit with a secret, a delete without a look, a claim without a fact. The gate wins, not the model.
Skills
Repeatable procedures written down once and run the same way every time: release, review, fact-check. The AI follows the sheet, not its mood.
Loops
Nightly runs with a budget cap and a score. Each run is measured against a fixed rubric, and the record decides what changes next.
security
  • You talk to one secretary AI. It coordinates the other models behind the scenes; they never contact you.
  • Nothing leaves without a record.
  • Money and publishing need human approval.

The design philosophy behind AGIAS

Direct

Set the AI's direction

Write the spec. Let the models build. Verify and correct. Every contributing model is named.

Record

Ledger before code

The reason is written before the change. Rejections are kept alongside adoptions.

Manage

Code on GitHub, records in OBSIDIAN

Code is versioned on GitHub. Decisions and records live in the OBSIDIAN vault. The machine and its ledger are handed over at delivery.

  • Your mail and material are kept in the operator's own OBSIDIAN vault and used only for your request.
